# Data Directory

This folder contains static JSON config files used by the server at runtime.

## Files

| File | Description |
|------|-------------|
| `avatar_items.json` | All available avatar items |
| `consumables.json` | Consumable items catalog |
| `equipment.json` | Equipment catalog |
| `game_configs.json` | GameConfigs (game mode settings) |
| `config_v2.json` | ConfigV2 (client configuration) |
| `rooms.json` | Default importable rooms |

> These files are loaded at startup and cached in memory.
